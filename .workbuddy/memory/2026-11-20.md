## 修复项目启动报错（NBSP 非法字符）
- 现象：`node server.js` / `npm test` / `npm run start` 均报 `ERR_INVALID_PACKAGE_CONFIG: Invalid package config .../package.json`。
- 根因：`package.json`、`config.json`、`server.js` 中混入了大量 NBSP（U+00A0 / UTF-8 `C2 A0`）作为缩进与空格。JSON 规范只允许普通空格，导致解析失败。
- 修复：用 Python 将上述 3 个文件中的所有 U+00A0 统一替换为普通空格（U+0020），共替换 package.json 46 处、config.json 224 处、server.js 4207 处。
- 验证：JSON 解析正常；`npm test` 18/18 通过；服务启动成功，首页与 /status 返回 200；上游 5 源全部加载成功，聚合结果 1338 站 / 44 直播 / 80 解析，/config 接口输出有效 JSON。
- 经验：若以后再出现类似 `ERR_INVALID_PACKAGE_CONFIG`，优先检查文件是否混入了 NBSP/全角空格等不可见字符（用 `xxd` 或按码点统计排查）。
